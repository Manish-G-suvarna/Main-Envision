Manual Setup:
   1. Run: npm install --save-dev wrangler
   2. Run: wrangler login
   3. Run: wrangler d1 create envision_db
   4. Update: wrangler.toml with Database ID
   5. Run: wrangler d1 execute envision_db --file=./backend/migrations/0001_schema.sql
   6. Run: npm install
   7. Run: npm run worker:dev  (test locally)
   8. Run: npm run worker:deploy  (deploy!)
